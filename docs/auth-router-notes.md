# Нотатки до маршрутизатора авторизації

До src/server/auth/router.ts додано помірну кількість українських пояснень від першої особи: підключення маршрутів /api/auth, перевірки POST, реєстрація, хешування пароля, параметризований SQL, зайнятий логін, вхід, створення сесії та HttpOnly-cookie, GET /me і вихід.

Перевірка 04.11.2026: esbuild із вилученням коментарів підтвердив незмінність виконуваного коду окремо для робочого файлу і версії коміту. npm run typecheck та npm run build пройшли. Робочі облікові записи, сесії й БД для цього завдання не змінювалися.

Наявне до завдання форматування router.ts збережене в робочій папці та не включене до коміту. Інші попередні користувацькі редагування також збережені.
