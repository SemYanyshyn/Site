# Пояснення Dockerfile для себе

04.11.2026 перед кожною з 25 інструкцій Dockerfile додано прості українські пояснення від першої особи: «беру», «копіюю», «встановлюю», «запускаю». На початку пояснено різницю між образом і контейнером та значення шляхів усередині образу. Початкові англомовні коментарі замінено українськими.

Пояснено етапи base/build/production-dependencies/runtime, Node.js і npm, робочу папку, залежності, копіювання, збирання, змінні середовища, власника файлів, користувача, порт, сигнал зупинки та команду запуску. Окремо розібрано sha256, ./, *, &&, --from, --chown і квадратні дужки.

Перевірка пройшла: усі 25 рядків інструкцій після вилучення коментарів і порожніх рядків дослівно збігаються з початковим файлом. Перед кожною інструкцією є український коментар; директив парсера не додано; git diff --check без помилок. Образи, контейнери й Kubernetes для цієї зміни не перебудовувалися та не перезапускалися. Попереднє незакомічене форматування scripts/deploy-local.mjs збережено поза комітом.

Значення інструкцій звірено з [офіційним довідником Dockerfile](https://docs.docker.com/reference/dockerfile/).

У робочому Dockerfile збережено паралельні редагування вступних коментарів; вони залишаються поза комітом. Коміт містить повний підготовлений варіант пояснень. Самі 25 інструкцій однакові в обох версіях.
