# Пояснення kind-config.json для себе

До deploy/kind-config.json додано українські пояснення від першої особи до всіх налаштувань: типу та версії конфігурації, імені кластера, локального API, вузла control-plane, образу, міток і зіставлень портів HTTP/HTTPS.

Звичайний JSON не підтримує коментарі // або #. Тому нотатки збережені як спеціальні поля _comment і _comment_*. Невеликий helper scripts/kind-config.mjs прибирає тільки ці поля перед підстановкою значень і передачею конфігурації інструменту kind. Це підключено тільки до читання шаблону kind у scripts/deploy-local.mjs; загальний JSON reader і решта конфігурацій не змінюються.

Перевірено: файл парситься як JSON; після вилучення нотаток об’єкт дослівно за значеннями й типами збігається з початковою конфігурацією. Окремо перевірено вкладені масиви, false/0/null та збереження ключів, які не є нотатками. Імпорти та синтаксис deploy helper працюють; npm run typecheck, npm run build і всі 51 test:unit пройшли. Кластер, Colima, образи та робочі дані для цієї зміни не перезапускалися.

Попереднє незакомічене форматування deploy-local.mjs збережено поза комітом. Попередні паралельні редагування Dockerfile не змінювалися.
