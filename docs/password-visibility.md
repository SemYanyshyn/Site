# Кнопка видимості пароля — 04.11.2026

У спільну форму входу та реєстрації додано кнопку «Показати / Приховати». Вона змінює лише тип поля між password і text, зберігаючи його значення. Кнопка має type=button, підпис для допоміжних технологій та зв’язок aria-controls із полем.

Під час надсилання форми пароль автоматично приховується, а кнопка блокується разом із fieldset. Зміна режиму, очищення поля, вихід, завершення сеансу та демонтаж форми також повертають прихований стан. Стилі додано у SCSS відповідно до наявного зеленого оформлення.

Перевірки: typecheck/build PASS; усі 66 наявних клієнтських тестів PASS. У справжньому ізольованому headless Chrome пройшли 11 перевірок: початковий прихований стан; показ і приховування без зміни значення чи submit; обидва режими й скидання стану між ними; клавіша Space; відсутність POST від перемикання; приховування та блокування під час submit; прихований стан після відмови; розміщення на ширині 360 px. Мобільний знімок фактично оглянуто.

Браузерна перевірка стосувалася зібраного frontend: тимчасовий loopback-сервер повертав ізольовані 401-відповіді API. Це не повторна наскрізна перевірка реальної авторизації. Тимчасові сервер і Chrome зупинено, профіль вилучено. Робочу БД, Kubernetes та публічне демо не змінювали; залежності не додавали.

Попередні редагування Dockerfile, deploy/k8s/app.json, scripts/deploy-local.mjs та src/server/auth/router.ts збережено поза комітом цього завдання.
