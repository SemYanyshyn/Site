# Мої пояснення спільних типів і перевірок

05.11.2026 — додав українські коментарі від першої особи до всіх шести TypeScript-файлів `src/shared` без крапок наприкінці коментарів

Пояснив призначення інтерфейсів, статусів і основних полів, різницю між TypeScript-типами та перевіркою JSON під час роботи, нормалізацію логіна, Unicode пароля, ліміти задач, прогноз черги, метрики адміністратора та публічну адресу API

Англійські пояснення переклав, у [src/shared/README.md](../src/shared/README.md) додав мапу файлів і коротку пам’ятку синтаксису

## Перевірки

- Усі рядки поза коментарями в шести файлах незмінні
- Esbuild-порівняння дає однаковий виконуваний JavaScript до й після змін
- Коментарі не закінчуються крапками
- `npm run typecheck` — PASS
- `npm run build` — PASS
- `npm run test:client` — 66 PASS
- `npm run test:unit` — 54 PASS
- `git diff --check` — PASS

Нові тести для коментарів не додавав, робочу базу, deployment і тунелі не перезапускав

Наявні користувацькі зміни у `src/client/jobs-view.ts` та `src/server/route/algorithm.ts` не редагував і до коміту цих пояснень не включав
