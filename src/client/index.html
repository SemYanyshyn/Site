Спостереження за застосунком

Адміністрування

Панель лише для читання. CPU та RAM належать контейнерам app разом із їхніми потоками. Ready, вільний обчислювальний слот і бажані HPA replicas — різні показники.

Джерела й автоматичне розширення

CPU — використані ядра за вказане вікно; 1000 мCPU = 1 ядро. RAM — working set у MiB (1048576 байт). Відсоток CPU обчислений від request і може перевищувати 100%. Невідоме значення не дорівнює нулю; сума має вказане покриття.

Поточні app-сервери

Pod UID — фізичний pod; process UUID — конкретний HTTP-процес та його єдиний worker-слот. Зайнятість визначає БД, а не CPU.
