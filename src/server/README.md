# Як я орієнтуюся в backend Courier Route

Backend приймає HTTP-запити браузера, перевіряє користувача, працює з PostgreSQL і керує розрахунками маршруту

## Як проходить запит

1. У `index.ts` запускаю сервер і створюю спільні ресурси процесу
2. У `app.ts` підключаю перевірки й обираю API-маршрут
3. У `http` перевіряю Origin і формат JSON, в `auth` — cookie та сесію
4. У `jobs/router.ts` перевіряю вхід, а через repository зберігаю queued-задачу
5. Диспетчер забирає задачу з PostgreSQL і передає її RouteExecutor
6. Worker у `route` рахує маршрут окремо від HTTP-потоку
7. Диспетчер зберігає прогрес і результат, а браузер читає їх через API

Це кілька HTTP-запитів у часі, а не одне тривале очікування відповіді POST

## Кореневі файли

- [`config.ts`](config.ts) — Тут збираю налаштування HTTP-сервера зі змінних середовища й одразу перевіряю їх
- [`database.ts`](database.ts) — Тут відкриваю спільний пул підключень до PostgreSQL і перевіряю готовність схеми
- [`app.ts`](app.ts) — Тут збираю Express-застосунок, тобто правила обробки HTTP-запитів від браузера
- [`index.ts`](index.ts) — Це головна точка запуску backend, яка з’єднує HTTP, PostgreSQL і виконавця задач
- [`admin-role.ts`](admin-role.ts) — Це окрема команда для мене як оператора, щоб змінити роль уже зареєстрованого користувача

## Що собі не плутаю

- HTTP-сервер обробляє запити, PostgreSQL зберігає дані, worker виконує важкі обчислення
- Kubernetes запускає контейнери й керує репліками, його конфігурація лежить у `deploy/k8s`
- `request` містить запит браузера, `response` формує відповідь, `next` передає керування далі
- `Promise` представляє майбутній результат, `await` чекає його без блокування всього HTTP-процесу
- Інтерфейс або `type` TypeScript описує дані для перевірки типів, але не перевіряє довільний JSON під час роботи
- Cookie з токеном упізнає сесію, але пароль і його хеш браузеру назад не повертаю
- Локальна готовність `/api/ready` не доводить доступність зовнішнього HTTPS-тунелю

Коментарі в 40 серверних файлах пояснюють основні блоки, а не змінюють їхню поведінку
