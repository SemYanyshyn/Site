# Підготовка схеми PostgreSQL

Тут перевіряю базу й послідовно застосовую SQL-міграції з кореневої папки `migrations`

Міграція — це версійована зміна структури таблиць, а транзакція дозволяє застосувати її цілком або відкотити

Хеш у `schema_migrations` допомагає помітити зміну вже застосованого файлу

`npm run db:check` перевіряє підключення, а `npm run db:migrate` явно застосовує міграції

## Моя мапа файлів

- [`check.ts`](check.ts) — окрема команда швидкої перевірки підключення до PostgreSQL
- [`migrate.ts`](migrate.ts) — застосовую SQL-міграції, тобто послідовні зміни структури таблиць
- [`migration-comment-updates.ts`](migration-comment-updates.ts) — зберігаю точні пари старого й нового SHA-256 для погоджених правок лише коментарів міграцій

Код і SQL-файли не містять коментарів; пояснення зберігаються в README
