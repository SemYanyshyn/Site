# Спільні HTTP-перевірки

Тут перевіряю запит ще до роботи конкретного API-маршруту

Origin — це протокол, хост і порт сторінки, наприклад `https://localhost:8443`

CORS визначає, з яких адрес браузер може читати API, а JSON guard додатково перевіряє POST перед зміною даних

Ці перевірки не замінюють сесію користувача й контроль власника задачі

## Моя мапа файлів

- [`cors.ts`](cors.ts) — керую CORS, тобто дозволом браузеру читати API з конкретного origin
- [`json.ts`](json.ts) — перевіряю POST-запити, які можуть змінити дані через API

Докладні пояснення основних блоків залишаю безпосередньо в коментарях відповідних файлів
